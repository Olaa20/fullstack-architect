# 🧱  HTML5 & Sémantique

## 🎯 Objectif
Créer une page web structurée et accessible avec HTML5 + CSS3 de base.

## 📂 Contenu
- `index.html` → Page profil personnelle
- `forms.html` → Formulaire de contact
- `assets/css/style.css` → Styles simples & cohérents

## ✅ Checklist Validation
- [ ] Structure HTML5 valide
- [ ] Sémantique respectée (`header`, `main`, `section`, `footer`)
- [ ] Formulaire accessible avec labels reliés
- [ ] Navigation fonctionnelle entre pages
- [ ] Page testée sur mobile (responsive basique)
- [ ] Lighthouse Accessibilité ≥ 90
- [ ] Screenshots ajoutés dans `frontend/docs/`
