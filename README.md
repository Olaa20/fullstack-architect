# Fullstack Architect — Parcours 6 mois

Objectif: devenir ingénieur FullStack capable de concevoir, développer et architecturer des apps web **sécurisées, performantes et documentées**.

## Structure (évolutive)
Nous allons construire progressivement, phase par phase. D'abord **Phase 1** (Python, Git, CLI), puis SQL, Frontend, Backend, DevOps, Capstone.

## Phase 1 — Fondations
- Python: variables, conditions, boucles, fonctions, modules
- Git/GitHub
- Mini-projets: Calculatrice CLI, Convertisseur de devises
- Projet de fin: Gestionnaire de contacts (CLI)
